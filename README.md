# TechnoShop - Интернет-магазин техники (Django)

Учебный проект по веб-программированию. Полноценный прототип интернет-магазина.

## 🛠 Стек технологий
- Python 3.14 / Django 6
- SQLite (база данных)
- Bootstrap 5 (фронтенд)
- AJAX + DeepSeek API (AI-консультант)

## 🚀 Реализованный функционал
- Каталог товаров с фильтрацией по категориям
- Корзина на сессиях (доступна без авторизации)
- Оформление заказа с сохранением в базу данных
- Регистрация, авторизация и личный кабинет («Мои заказы»)
- Кастомизированная админ-панель Django
- **Фишка:** AI-консультант в карточке товара (интеграция с DeepSeek API через AJAX)

## ⚙️ Как запустить
1. Клонируйте репозиторий.
2. Создайте виртуальное окружение: `python -m venv venv`
3. Активируйте его: `venv\Scripts\activate`
4. Установите зависимости: `pip install -r requirements.txt`
5. Примените миграции: `python manage.py migrate`
6. Создайте суперпользователя (админа): `python manage.py createsuperuser`
7. Запустите сервер: `python manage.py runserver`
